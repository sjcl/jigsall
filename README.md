# Puzzella - マルチプレイヤージグソーパズル

Bevyゲームエンジンを使用したマルチプレイヤージグソーパズルゲームです。

## 機能

- 任意の画像をジグソーパズルに変換
- リアルタイムマルチプレイヤー機能
- ホスト/参加システム
- ドラッグ&ドロップによるパズル操作
- 自動スナップ機能
- 進行状況表示

## 使い方

1. アプリケーションを起動
2. 「ゲームをホストする」または「ゲームに参加する」を選択
3. ホストの場合：
   - グリッドサイズを設定
   - ポート番号を設定
   - ゲームを開始
4. 参加の場合：
   - ホストのIPアドレスを入力
   - ポート番号を入力
   - 接続

## 構成

- `src/main.rs` - アプリケーションエントリーポイント
- `src/game.rs` - ゲームプラグイン
- `src/components.rs` - ゲームコンポーネント
- `src/resources.rs` - ゲームリソース
- `src/systems.rs` - ゲームシステム
- `src/puzzle.rs` - パズル生成・操作
- `src/networking.rs` - ネットワーク機能
- `src/ui.rs` - ユーザーインターフェース

## ビルド

```bash
cargo build --release
```

## 実行

```bash
cargo run
```

## 必要なアセット

- `assets/puzzle_image.png` - パズルに使用する画像

## 技術仕様

- Bevy 0.14.2 (安定版)
- Renet 0.0.15 (ネットワーキング)
- Egui 0.29 (UI)
- Serde (シリアライゼーション)

## 注意事項

このプロジェクトはWindows/macOS/Linux環境での実行を想定しています。WSL環境ではwinitライブラリの制限によりコンパイルができません。

Bevy 0.15.3とrenet 1.0.0の組み合わせでgpu_allocatorの型競合が発生するため、安定版のBevy 0.14.2を使用しています。

Windows環境で実行する場合：
```bash
# PowerShellまたはコマンドプロンプトで実行
cargo run
```
