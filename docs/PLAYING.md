# 遊び方ガイド

[Jigsall の紹介と起動方法](../README.md)に戻る。

## 画像とピース数

タイトルの「シングルプレイ → 新しいパズル」で画像を選び、ピース数を設定して「はじめる」を押します。初期設定は「正方形に近づける」で、100 ピースを目安にします。

「正方形に近づける」は画像の縦横比に合わせて分割数を決めるため、実際のピース数は目安と異なる場合があります。「ピース数を指定」では指定数を優先し、「縦・横で指定」では各辺最大 1000、合計最大 100 万ピースまで指定できます。操作欄のすぐ下で、実際のピース数・縦横の分割数・1ピースのサイズを確認できます。サイズはパズル画像を分割した寸法で、凸凹は含みません。「詳細設定」の「シード値」を変えると、形と最初の並び方が変わります。

「ピースの回転を有効にする」は初期設定ではオフです。オンにすると開始時の向きが 90° 単位でランダムになり、プレイ中も回転できます。正方形ではない分割でオンにすると、縦横の長さが入れ替わることを警告します。そのまま開始することもできます。この設定はパズル開始時に決まり、保存したパズルや参加先の部屋では元の設定を引き継ぎます。

新しいパズルでピースがつながる距離は、1ピースの短い辺の20%に自動設定されます。保存したパズルを再開する場合は、そのパズルに記録された距離を使います。

読み込める画像形式は PNG・JPEG・BMP・GIF・WebP です。元画像には次の上限があり、すべてを満たす必要があります。

| 項目 | 上限 |
| --- | --- |
| ファイルサイズ | 512 MiB |
| 縦・横それぞれの長さ | 32,768 px |
| 総画素数 | 67,108,864（8192 × 8192 相当） |

上限を超えた画像は縮小・画素のデコード前に拒否します。読み込み可能な画像でも、表示用の画像は GPU の上限と画像メモリ予算に合わせて縮小されます。「設定 → グラフィック」で画像のメモリ予算を変更でき、次の画像選択または保存データのロードから反映します。保存される元画像の品質は変わりません。処理の詳細は [アーキテクチャ](ARCHITECTURE.md#生成と状態遷移)、予算の計算は [設定ファイル](SETTINGS.md#パズル画像のメモリ予算)を参照してください。

## 操作一覧

以下は初期設定の操作です。ゲーム画面上部の「操作方法」でも確認できます。

| 操作 | 入力 |
| --- | --- |
| 選択・ドラッグ | 左クリック / 左ドラッグ |
| 選択の追加・解除 | Ctrl + 左クリック |
| 範囲選択 | 空きスペースから左ドラッグ（Ctrl 併用で追加） |
| 複数ピースの移動 | 選択済みのピースを左ドラッグ |
| 視点の移動 | 右ドラッグ |
| 拡大・縮小 | マウスホイール |
| ドラッグ中の画面スクロール | ピースをドラッグして画面端へ |
| 90° 回転（反時計回り / 時計回り） | Q / E（回転を有効にしたパズルのみ） |
| 一時停止・再開 | Esc |
| プレイヤー一覧 | Tab を押している間 |
| パフォーマンス表示切り替え | F3（FPS のみ → 詳細 → 非表示） |

### 選択と連結

未選択のピースをクリックすると選択を置き換えます。選択済みのピースをドラッグすると、選んだピース同士の相対位置を保って移動します。重なった場所では手前の選択可能なピースを選びます。範囲選択は、指定範囲に形がかかる、奥に隠れた選択可能なピースも含みます。完全に透明な画像部分は選択しません。

元画像で正しく隣り合い、同じ向きのピースは、盤面の外でも近くで離すとつながります。つながった部分はクリック・Ctrl・範囲選択・ドラッグで全体を扱います。まだつながっていない複数のまとまりも、同時に選んで移動できます。

正解位置の近くで離すと盤面にはまり、配置済みのピースは動かせなくなります。つながった部分は全体が配置されます。すべてのピースを配置すると完成画面へ進みます。

UI 上を押してもピースの移動は始まりません。一時停止したり、ゲームのウィンドウからフォーカスが外れたりすると、保持を解除して未確定の範囲選択を取り消します。

### 回転

回転を有効にしたパズルでは、Q / E で選択中のピースを回転します。選択がなければカーソル下のピースが対象です。つながっている場合はその全体が回転し、複数のまとまりを選んでいる場合はそれぞれの中心で回転します。ドラッグ中も回転して、そのまま移動を続けられます。

向きが異なるピースはつながりません。盤面には正しい向き（0°）でのみ配置できます。配置済みのピースや、ほかのプレイヤーが保持しているまとまりは回転できません。実装と検証は [回転の仕様](ROTATION.md)を参照してください。

## 保存と再開

一時停止メニューや完成後のメニューの「ゲームを保存」で、タイトル（最大 80 文字）を入力してローカルに保存できます。「シングルプレイ → つづきから」で保存を選ぶと、連結・配置・進捗を復元します。元画像も品質を変えずに保存するため、元ファイルを移動・削除しても再開できます。手動保存から再開したゲームは、通常の保存で同じ手動セーブを更新します。

シングルプレイまたはホストとしてプレイしているときは、「タイトルへ戻る」や「ゲームを終了」を押すと保存画面が開きます。「保存してタイトルへ戻る」「保存して終了」は、保存が成功してから移動・終了します。保存に失敗した場合は、その画面で再試行できます。「保存せずにタイトルへ戻る」「保存せずに終了」を選ぶと、もう一度確認します。確認画面の「キャンセル」で保存画面に戻り、保存画面の「キャンセル」で離脱を取り消せます。

完成したパズルに一度でも保存履歴（手動保存・オートセーブ）がある場合は、保存画面や未保存の確認を出さずにタイトルへ戻る・終了します。完成前に保存した履歴や、保存データから再開した場合も対象です。完成状態を記録したい場合は、戻る・終了する前に「ゲームを保存」を選んでください。

ウィンドウの閉じるボタンや Alt+F4 でも同じ判定を使い、保存の確認が必要な場合は一時停止して保存画面を開きます。確認が終わるまでウィンドウは閉じません。キャンセルした場合は、一時停止メニューからプレイを再開できます。

シングルプレイと、マルチプレイのホストにはオートセーブがあります。初期設定はプレイ中の 5 分ごとで、手動保存とは別にゲームごとに最新 1 件を残します。「設定 → 一般」で間隔（1〜60 分）、保存件数上限、オン・オフを変更できます。上限を超えたオートセーブは、新しい保存が成功した後で古い順に削除します。一時停止中や完成後はオートセーブの時間を加算しません。

保存中は画面上部に表示し、ロード一覧では日時の横に「オートセーブ」と表示します。Steam Cloud は未実装です。保存先・形式・互換性は [ローカル進捗保存](PERSISTENCE.md)を参照してください。

## 完成したパズルを見る

完成画面の「完成したパズルを見る」で盤面を眺められます。マウスホイールで拡大・縮小、右ドラッグで視点を移動します。Esc のメニューから「タイトルへ戻る」を選ぶか、完成画面から直接タイトルに戻れます。

## マルチプレイ

まず「マルチプレイ」で「部屋を開く」か「部屋に参加」を選びます。Room Code 方式は、全員が `rendezvous` 対応ビルドを使い、運用側で Internet 接続を設定した場合に利用できます。利用できる場合、最初は「ルームコード」が選ばれます。接続方法は実際の部屋設定・参加フォームで変更できます。

ホストはパズルを選んでパスワードを設定します。開始後に、プレイを止めない招待案内が表示されます。上部UIには「ホスト中」と表示されます。ルームコードは上部UIと招待案内で初期状態では非表示になっており、「表示」「非表示」で切り替えられます。非表示中もコピーでき、コピーすると完了表示が出ます。Esc のマルチプレイメニューにはルームコードを表示しません。参加者は「マルチプレイ → 部屋に参加 → ルームコード」でコードとパスワードを入力します。ホストは先に遊び始めることができ、ほかの人は途中から参加できます。画像と進行状態の受信後に同じパズルに入ります。受信待ち・受信中・同期中は、それぞれの状態が表示されます。

Internet が未設定の場合は「Direct IP / LAN」を利用します。ルームサービスが途中で切断されると新しい参加者を受け付けられなくなりますが、成立済みのゲーム接続は継続します。

Direct IP では、参加する全員が `gns` を有効にしたビルドを使います。[起動コマンド](../README.md#マルチプレイ)を参照してください。

1. ホストは「マルチプレイ → 部屋を開く」で、新しいパズルまたは保存済みのパズルを選びます。新しいパズルでは先に「パズル」タブが開くので、画像と分割方法を選び、右下の「マルチプレイ設定へ」を押します。ゲームの開始は「部屋の設定」から行います。
2. 「部屋の設定」で接続を受け付けるアドレスとパスワードを指定し、「部屋を開いてはじめる」を押します。パズルの準備ができると参加受付を開始します。
3. ホストは参加者に、この PC の実際の IP アドレスまたはホスト名、ポート番号、パスワードを伝えます。
4. 参加者は「マルチプレイ → 部屋に参加 → Direct IP / LAN」に入力します。画像と進行状態を受け取り、準備ができると同じパズルに入れます。

参加後にホストとの接続が失われた場合、切断画面の「最後の状態を保存」からタイトルを入力してローカルに保存できます。最後に同期された状態を保存するため、移動中だったピースは最後に確定した位置になります。保存後は「シングルプレイ → つづきから」で再開できます。保存に失敗した場合は、その場で再試行できます。「未保存の状態を破棄して戻る」を選ぶと、未保存の状態を破棄して参加画面に戻ります。保存が完了した場合は「参加画面に戻る」と表示されます。

入力したパスワードは接続方法を変えたりフォームを離れたりすると消去されます。部屋を開いた後にパスワードを再表示することはできないため、開始前に参加者へ伝えてください。プレイヤー名は部屋設定・参加フォームで直接入力し、「名前を保存」または入力欄のEnterで保存できます。名前の編集・保存で入力済みのパスワードは消去されません。

プレイ中にメニューを開いても、ほかの人のプレイは続きます。ホストが部屋を閉じると全員の接続が切れるため、保存して戻る場合も確認画面に注意が表示されます。参加者は部屋を抜けても、ほかの人のプレイは続きます。プレイヤー一覧は Tab を押している間、または上部のプレイヤー数をクリックして表示できます。自分・ホストの印と、カーソルに対応する色が表示されます。

参加先は IPv4 なら `192.168.1.10:43576`、IPv6 なら `[2001:db8::1]:43576`、ホスト名なら `example.com:43576` の形式です。ホスト側の待受けには IP アドレスを指定します。`0.0.0.0` はすべての IPv4 アドレスで接続を受け付ける指定で、参加者へ伝えるアドレスには使いません。パスワードは、半角英数字なら 8〜128 文字で指定できます。

インターネット経由ではルーターのポート開放が必要な場合があります。Direct IP の接続先は手動で指定します。ゲーム内の「接続について」でも確認できます。通信方式やテストは [ネットワーク transport](NETWORK_TRANSPORT.md)、ゲームとの統合は [Direct-IP runtime](DIRECT_IP_RUNTIME.md)を参照してください。

## 設定を変える

タイトル画面またはゲーム中の Esc メニューの「設定」から開けます。「閉じる」または Esc で、設定を開いた元の画面へ戻ります。ゲーム中に開いた場合は Esc メニューへ戻り、そこからプレイを再開できます。完成したパズルを見ているときも同じ操作で設定を開けます。

**背景色**：「設定 → グラフィック → ゲーム画面の背景色」で「ダーク」（既定）または「ライト」を選び、「適用」で反映・保存します。

**表示**：「設定 → グラフィック」で画面モード・解像度・最大 FPS を変更し、「適用」で反映します。画面モード・解像度を変えた場合は、15 秒以内に「変更を維持」で確定してください。「元に戻す」または時間切れで以前の設定に戻ります。[表示設定の詳細](DISPLAY_SETTINGS.md)を参照してください。

**言語**：「設定 → 一般 → 言語」で自動・English・日本語を選べます。再起動なしで切り替わり、次回起動時も復元します。自動では OS の言語を使い、未対応なら英語になります。翻訳カタログとフォントは [ローカライズ](LOCALIZATION.md)を参照してください。

**キー割り当て**：「設定 → キー設定」で各操作に「キー1」「キー2」を設定でき、どちらでも操作できます。割り当て欄をクリックしてキーを押し、すべて離すと登録されます。Shift + R や A + B など、2 キーの同時押しも使えます。左右の Shift / Ctrl / Alt / Super は共通です。「適用」で保存し、次回起動時も復元します。「解除」で割り当てを空にし、「初期設定に戻す」で標準操作に戻せます。

Esc は固定で、入力待ちではキャンセル、それ以外では戻る・一時停止に使います。同じ割り当ての重複は保存できません。1 キーとそのキーを含む 2 キーを押した場合は、2 キーの操作が優先されます。

設定ファイルの場所と反映タイミングは [設定ファイル](SETTINGS.md)を参照してください。
